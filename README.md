# Unsass

The Unsass tools monorepo.

## Introduction

Small, dependency-free Sass toolkits published under the `@unsass` scope. This repository hosts small building blocks
used by other Unsass libraries.

## Packages

| Package                            | Description                                                        |
|------------------------------------|--------------------------------------------------------------------|
| [@unsass/string](/packages/string) | Composable Sass functions to manipulate, search and trim strings.  |
| [@unsass/types](/packages/types)   | Sass functions to check the type of a value.                       |
| [@unsass/var](/packages/var)       | Sass functions to create, read and parse the `var()` CSS function. |
